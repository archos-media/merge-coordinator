# Support

**Maintained, not supported.** Archos Media maintains merge-coordinator for
its own work and shares it as it is.

- Issues are read. No response time is promised.
- Bugs with a reproduction and the plugin version come first. The bug form
  asks for what is needed.
- Ideas are welcome and may be declined: the scope is kept narrow on purpose
  (GitHub, Claude Code, the landing sequence and what it needs).
- Questions about setting it up: start with the
  [adoption guide](skills/merge-coordinator/references/adopting.md), then open
  an issue.
- Security problems go through [SECURITY.md](SECURITY.md), never a public
  issue.

Issues may be read and answered first by an AI agent working for the
maintainer. A person decides what changes.
